# Contributing

Thanks for contributing to the ACV API Automation documentation and project. Follow these guidelines when adding or editing tests and docs.

1. Fork and create feature branches for changes.
2. Write clear commit messages referencing the JIRA or ticket number.
3. For code changes add unit tests and update `LLD.md` as needed.
4. For documentation changes, keep the docs in `Documentation/acv-api-automation/` and add diagrams in Mermaid format.
5. Run the full test suite locally before creating a PR.

Style
- Use present tense and active voice.
- Keep diagrams in Mermaid and place them in `diagrams.md` as canonical sources.

Contact
- For architecture or infra questions, contact the ACV platform team.
