# Glossary

- ACV: Automated Customer Verification (project name shorthand)
- CI: Continuous Integration
- Test Run: A single execution of a test suite with results and artifacts
- Smoke Test: A quick subset of tests that validate critical flows
- Contract Test: Tests that validate API schema and behavior guarantees
- Cucumber: BDD test framework using Gherkin feature files
- RestAssured: Java DSL for testing REST services
- POJO: Plain Old Java Object used for JSON (de)serialization
- ExtentReports: Reporting library that generates HTML/PDF test reports
