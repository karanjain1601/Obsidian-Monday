# High-Order PDEs on Any Mesh (Discontinuous Galerkin)

**Alt title:** "The Method That Does High-Order CFD on Any Mesh"
**Difficulty:** 9/10 | **Prereq:** A003 (FEM basics), PDE theory, Python/NumPy

---

## Opening Hook (0:00–1:00)

"Standard finite elements are continuous — the solution doesn't jump across element boundaries. Standard finite differences need structured grids — you can't put them on a brain MRI mesh. Standard finite volumes are only first- or second-order accurate — not enough for aeroacoustics or seismology. What if you want high-order accuracy on any unstructured mesh, and you don't mind if the solution has jumps at element boundaries?"

"That's Discontinuous Galerkin. Inside each element: a high-degree polynomial (order 3, 5, 7). At the boundary: a numerical flux couples the elements together. The result: spectral-like accuracy with finite element flexibility. And unlike continuous Galerkin: the mass matrix is block-diagonal — inverting it is trivial. Locality is perfect for GPUs and MPI parallelism."

A triangular mesh of a wing cross-section appears. Each triangle is colored differently — inside each one, a smooth polynomial approximation of the flow. At the interfaces: small jumps, coupled by Riemann fluxes. "This is the aircraft aeroacoustics solver of the future. And we're going to build the core algorithm from scratch."

## The Naive Attempt

Naive: use standard Galerkin FEM for the linear advection equation, hoping high-order polynomials on continuous elements will give accurate wave propagation.

```python
import numpy as np
from scipy.sparse import lil_matrix
from scipy.sparse.linalg import spsolve

# Naive: continuous Galerkin for linear advection: du/dt + a*du/dx = 0
# Problem: continuous Galerkin for hyperbolic PDEs is unstable without upwinding

a = 1.0    # advection speed
L = 2*np.pi
N_elem = 20    # number of elements
p = 3          # polynomial order per element
N_nodes = N_elem * p + 1  # continuous: nodes shared at boundaries
x = np.linspace(0, L, N_nodes)
dx_elem = L / N_elem

# Continuous Galerkin: Lagrange basis on each element
# The global mass matrix M and stiffness matrix K
def shape_functions_1d(xi, p):
    """Lagrange shape functions on reference element [-1,1] at degree p."""
    # p+1 Gauss-Lobatto nodes
    from numpy.polynomial.legendre import leggauss
    xi_nodes = np.linspace(-1, 1, p+1)
    # Lagrange interpolation
    N_funcs = []
    for k in range(p+1):
        numer = np.ones_like(xi) * 1.0
        denom = 1.0
        for j in range(p+1):
            if j != k:
                numer = numer * (xi - xi_nodes[j])
                denom *= (xi_nodes[k] - xi_nodes[j])
        N_funcs.append(numer / denom)
    return np.array(N_funcs)

# Build global mass + advection matrix for continuous Galerkin
# (simplified: just checking the instability)
from numpy.polynomial.legendre import leggauss
xi_gauss, w_gauss = leggauss(p+2)

M_global = np.zeros((N_nodes, N_nodes))
K_global = np.zeros((N_nodes, N_nodes))

for e in range(N_elem):
    x_L_e = e * dx_elem
    x_R_e = (e+1) * dx_elem
    jac = dx_elem / 2  # Jacobian: dx/dxi
    
    # Element-local DOFs (continuous: shared nodes)
    dof_e = list(range(e*p, e*p + p+1))
    
    for gi, (xi_g, w_g) in enumerate(zip(xi_gauss, w_gauss)):
        N_g = shape_functions_1d(np.array([xi_g]), p)[:, 0]
        # dN/dx = dN/dxi * dxi/dx = dN/dxi / jac
        dN_dxi = shape_functions_1d(np.array([xi_g+1e-8]), p)[:, 0]
        dN_dxi = (dN_dxi - N_g) / 1e-8  # finite difference for demo
        dN_dx = dN_dxi / jac
        
        for i in range(p+1):
            for j in range(p+1):
                M_global[dof_e[i], dof_e[j]] += jac * w_g * N_g[i] * N_g[j]
                # Advection: -a * dN/dx (integration by parts fails without upwinding)
                K_global[dof_e[i], dof_e[j]] += w_g * N_g[i] * a * dN_dx[j] * jac

# Initial condition: smooth Gaussian
u = np.exp(-50*(x - np.pi)**2)
print("Continuous Galerkin for advection:")
print(f"  Polynomial order p={p}, N_elem={N_elem}")
print(f"  Global system: {N_nodes}x{N_nodes}")

# Forward Euler time step (for demo)
dt = 0.001
# Solve: M du/dt = -K u
# Forward Euler: M u^{n+1} = M u^n - dt * K u^n
# -> u^{n+1} = u^n - dt * M^{-1} * K * u^n

# Check eigenvalues of M^{-1}K — if imaginary parts, oscillations guaranteed
from scipy.linalg import eig
M_np = np.array(M_global[:N_nodes, :N_nodes])
K_np = np.array(K_global[:N_nodes, :N_nodes])
try:
    evals = eig(K_np, M_np, right=False)
    max_imag = np.max(np.abs(evals.imag))
    print(f"\n  Max imaginary eigenvalue: {max_imag:.3f}")
    if max_imag > 0.01:
        print(f"  WARNING: Non-zero imaginary eigenvalues = oscillatory instability!")
        print(f"  CG for hyperbolic PDEs will generate spurious oscillations")
        print(f"  near discontinuities. NOT upwind. NOT dissipative.")
except:
    print("  Eigenvalue analysis failed (singular M). System is ill-posed!")
```

---

## The Moment of Failure

The eigenvalue analysis reveals complex eigenvalues — meaning the continuous Galerkin scheme has oscillatory, non-dissipative modes that grow under time stepping. Run the advection with a step function initial condition: Gibbs oscillations appear immediately and grow. With a smooth initial condition, the scheme is fine for a while, but round-off errors seeding high-frequency modes eventually generate oscillations.

"Continuous Galerkin applies integration by parts and does NOT introduce upwinding. For hyperbolic equations, information travels in one direction (upwind). The scheme doesn't know which direction. The result is a non-dissipative scheme that generates spurious oscillations. This is why spectral elements (continuous Galerkin with spectral basis) need artificial viscosity for hyperbolic problems — and why the research community moved to Discontinuous Galerkin."

---

## Why It Broke — The Physics

The linear advection equation du/dt + a·du/dx = 0 is hyperbolic: information travels at speed a. Any numerical scheme must respect this — it must be upwind-biased. Continuous Galerkin with standard Galerkin weighting: ∫ w (du/dt + a du/dx) dx = 0 → the stiffness matrix K is skew-symmetric (for constant a on uniform mesh), giving purely imaginary eigenvalues. No dissipation. Any high-frequency error oscillates forever rather than being damped.

Discontinuous Galerkin avoids this by: (1) allowing the solution to jump at element boundaries, (2) coupling elements through an upwind numerical flux at each interface. The upwind flux introduces the necessary dissipation.

The DG formulation: within each element Ω_k, multiply the PDE by a test function v_h, integrate by parts, and replace the boundary flux with a numerical flux F*:
$$\int_{\Omega_k} v_h \frac{\partial u_h}{\partial t} dx - \int_{\Omega_k} a \frac{\partial v_h}{\partial x} u_h dx + [v_h \cdot F^*(u_h^-, u_h^+)]_{\partial\Omega_k} = 0$$

The upwind flux: F*(u^-, u^+) = a·u^- if a > 0 (information from left). The minus sign denotes the value from inside the element; plus from outside.

---

## The One Concept

**Discontinuous Galerkin (DG)** is a finite element method that uses discontinuous polynomial approximation spaces, couples adjacent elements through carefully chosen numerical fluxes, and achieves high-order accuracy on arbitrary unstructured meshes. It naturally inherits the advantages of both finite elements (geometric flexibility, high-order accuracy, variational formulation) and finite volumes (conservation, upwinding, shock-capturing).

**DG formulation for 1D advection.** Expand u_h in element k: u_h(x,t) = Σ_j û_k^j(t) φ_k^j(x), where {φ_k^j} are polynomial basis functions supported only on Ω_k. The weak form on element k:

$$M_k \frac{d\hat{u}_k}{dt} = S_k \hat{u}_k - [F^*]_{\partial\Omega_k}$$

where M_k[i,j] = ∫_Ω_k φ^i φ^j dx (local mass matrix — p×p, block-diagonal!), S_k[i,j] = a ∫_Ω_k (∂φ^i/∂x) φ^j dx (local stiffness), and [F*] is the numerical flux contribution at the element boundaries.

The key property: **M is block-diagonal** — each element has its own p×p block, independent of all others. Inverting M is O(p³) per element, not O((N·p)³) globally. This makes DG embarrassingly parallel: each element update is independent except for the flux evaluation at boundaries.

**Basis choices.** Nodal DG (Hesthaven-Warburton style): use Lagrange interpolants on Gauss-Lobatto nodes within each element. u_h is specified by its values at the nodes. Operations become matrix multiplications. Modal DG: use Legendre polynomials P_n(ξ) as basis. Orthogonal → M = identity (in reference coordinates). Either is equivalent; nodal is more practical for nonlinear problems.

**Runge-Kutta DG (RKDG).** The DG spatial operator + explicit time stepping. The key constraint: the CFL condition for DG is dt ≤ C · h / (a · (2p+1)) — more restrictive than finite differences by the factor (2p+1). For p=5: dt must be 11× smaller than FD. This is offset by the higher spatial accuracy (h^{p+1} error decay) — for the same accuracy, DG uses fewer, larger elements.

**Numerical fluxes.** For linear advection: upwind flux = a·u^-. For Euler equations: Roe flux, Lax-Friedrichs flux, or exact Riemann solver (same as Godunov). For diffusion: local DG (LDG) introduces an auxiliary variable for the gradient, then uses a central flux for the diffusion term. For diffusion + advection: IP-DG (interior penalty) adds a penalty term proportional to the jump: F_diffusion* = {∇u_h}·n - (σ/h)[u_h], where {·} is the average and [·] the jump.

**hp-adaptivity.** DG supports both h-refinement (subdivide elements where the solution is rough) and p-refinement (increase polynomial order where the solution is smooth). The hp-adaptivity algorithm: use a smoothness indicator (e.g., decay of modal coefficients) to decide which refinement strategy. For smooth regions: p-refinement gives exponential convergence. For shock regions: h-refinement + limiters (TVB, WENO reconstruction of modal coefficients). Result: exponential convergence to the smooth solution, sharp shock capturing — the best of both worlds.

**DG vs. other methods.** vs. FV: DG naturally achieves high-order with p-refinement; FV needs wide stencils (non-local). vs. continuous FEM: DG allows unstructured meshes with hanging nodes, no global solve needed per timestep. vs. spectral: DG handles shocks; pure spectral methods blow up at discontinuities. DG is the dominant method in modern PDE solvers for aeroacoustics, seismology, magnetohydrodynamics, and radiative transfer.

## The Fix

Implement 1D DG for linear advection with upwind flux and RK4 time integration.

```python
import numpy as np
from numpy.polynomial.legendre import leggauss

# 1D DG for linear advection: du/dt + a*du/dx = 0
# Upwind flux, Legendre basis, RK4 time integration

a_adv = 1.0   # advection speed (positive: left to right)
L = 2 * np.pi
N_elem = 10   # number of elements
p = 4         # polynomial degree (p+1 DOFs per element)
N_dof = p + 1
N_total = N_elem * N_dof  # total DOFs (discontinuous)

# Element coordinates
x_elem = np.linspace(0, L, N_elem+1)  # element boundaries

# Gauss-Legendre quadrature on [-1, 1]
n_quad = p + 2
xi_q, w_q = leggauss(n_quad)

# Legendre basis functions on [-1,1]
from numpy.polynomial.legendre import legval

def legendre_poly(n, xi):
    """Legendre polynomial P_n(xi)."""
    coeffs = np.zeros(n+1); coeffs[n] = 1
    return legval(xi, coeffs)

def legendre_deriv(n, xi):
    """Derivative of Legendre polynomial."""
    if n == 0: return np.zeros_like(xi)
    coeffs = np.zeros(n); coeffs[n-1] = 1
    return n * legval(xi, coeffs)

# Build reference mass matrix M_ref[i,j] = int_{-1}^{1} P_i P_j d_xi
M_ref = np.zeros((N_dof, N_dof))
for i in range(N_dof):
    for j in range(N_dof):
        M_ref[i, j] = np.sum(w_q * legendre_poly(i, xi_q) * legendre_poly(j, xi_q))

# Build reference stiffness matrix S_ref[i,j] = int_{-1}^{1} (dP_i/d_xi) P_j d_xi
S_ref = np.zeros((N_dof, N_dof))
for i in range(N_dof):
    for j in range(N_dof):
        S_ref[i, j] = np.sum(w_q * legendre_deriv(i, xi_q) * legendre_poly(j, xi_q))

# Evaluate basis at endpoints
P_left  = np.array([legendre_poly(j, -1.0) for j in range(N_dof)])  # P_j(-1)
P_right = np.array([legendre_poly(j,  1.0) for j in range(N_dof)])  # P_j(1)

def init_condition(x):
    """Smooth Gaussian initial condition."""
    return np.sin(x)  # periodic: sin(x) on [0, 2pi]

# Initialize modal coefficients u_hat[elem, mode]
u_hat = np.zeros((N_elem, N_dof))
for e in range(N_elem):
    h_e = x_elem[e+1] - x_elem[e]
    jac = h_e / 2
    x_q = x_elem[e] + (xi_q + 1)/2 * h_e  # physical quadrature points
    u_vals = init_condition(x_q)
    # Project onto Legendre modes: u_hat_j = int u P_j d_xi / int P_j^2 d_xi
    for j in range(N_dof):
        P_j = legendre_poly(j, xi_q)
        u_hat[e, j] = np.sum(w_q * u_vals * P_j) / np.sum(w_q * P_j**2)

def eval_at_boundary(u_hat_elem, side):
    """Evaluate u_h at left (-1) or right (+1) boundary of element."""
    if side == 'left':
        return np.dot(P_left, u_hat_elem)
    else:
        return np.dot(P_right, u_hat_elem)

def dg_rhs(u_hat):
    """Compute DG right-hand side: M^{-1}(S_ref u - flux terms)."""
    rhs = np.zeros_like(u_hat)
    
    for e in range(N_elem):
        h_e = x_elem[e+1] - x_elem[e]
        jac = h_e / 2
        
        # Volume integral: (a/jac) * S_ref^T * u_hat[e]
        # Note: dP_i/dx = dP_i/dxi * 2/h, flux = a * u_h
        vol_term = (a_adv / jac) * (S_ref.T @ u_hat[e])
        
        # Interface fluxes (upwind: a > 0, so information comes from left)
        u_right_of_e = eval_at_boundary(u_hat[e], 'right')
        u_left_of_e  = eval_at_boundary(u_hat[e], 'left')
        
        # Right interface: flux out = a * u_right_of_e (from inside)
        # Upwind: u^- is from inside (current element), u^+ from right neighbor
        e_right = (e + 1) % N_elem
        u_left_of_next = eval_at_boundary(u_hat[e_right], 'left')
        F_right = a_adv * u_right_of_e  # upwind (a>0: take from left/current elem)
        
        # Left interface: flux in = a * u_right_of_prev
        e_left = (e - 1) % N_elem
        u_right_of_prev = eval_at_boundary(u_hat[e_left], 'right')
        F_left = a_adv * u_right_of_prev  # upwind: information from left element
        
        # Boundary terms: [v F*]_{boundary}
        # Right boundary contributes +P_j(+1) * F_right
        # Left boundary contributes -P_j(-1) * F_left
        boundary_term = P_right * F_right - P_left * F_left
        
        # RHS: M^{-1}(-boundary + vol)
        local_rhs = vol_term - boundary_term
        # Invert local mass matrix M_ref * jac
        rhs[e] = np.linalg.solve(M_ref * jac, local_rhs)
    
    return rhs

# RK4 time integration
dt = 0.01
T = 2 * np.pi / a_adv  # one full period (exact solution = initial condition)
n_steps = int(T / dt)
t = 0.0

for step in range(n_steps):
    k1 = dg_rhs(u_hat)
    k2 = dg_rhs(u_hat + 0.5*dt*k1)
    k3 = dg_rhs(u_hat + 0.5*dt*k2)
    k4 = dg_rhs(u_hat + dt*k3)
    u_hat = u_hat + (dt/6)*(k1 + 2*k2 + 2*k3 + k4)
    t += dt

# Evaluate solution and compute L2 error vs. exact (sin(x - a*T) = sin(x))
L2_err = 0.0
for e in range(N_elem):
    h_e = x_elem[e+1] - x_elem[e]
    jac = h_e / 2
    x_q = x_elem[e] + (xi_q + 1)/2 * h_e
    u_exact = np.sin(x_q - a_adv * T)
    u_dg = np.array([eval_at_boundary(u_hat[e], 'left')] * n_quad)  # schematic
    u_dg = sum(u_hat[e, j] * legendre_poly(j, xi_q) for j in range(N_dof))
    L2_err += np.sum(w_q * (u_dg - u_exact)**2) * jac

L2_err = np.sqrt(L2_err)
print(f"DG p={p}, N={N_elem} elements: L2 error after 1 period = {L2_err:.2e}")
print(f"Expected: O(h^{p+1}) = O(dx^{p+1}) = O({(L/N_elem)**(p+1):.2e})")
print(f"For p=4, expected ~{(L/N_elem)**5:.2e}")
```
