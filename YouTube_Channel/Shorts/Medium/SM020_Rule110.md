## Visual Hook (First 3 Seconds)
A single white cell on a black horizontal line, 400 pixels wide. Time flows downward — each new row is the next generation. In 3 seconds the 200 rows reveal a complex, intricate black-and-white tapestry of triangles, stripes, and gliders — structured chaos from one cell and three rules.

## Main Visual Sequence (0:03–0:50)
**0:03–0:10** — Rule 110 lookup table shown: 8 possible 3-cell neighbour patterns and their outputs (binary 01101110 = decimal 110). Each pattern/output pair shown as a small cell triple with an arrow to the new centre cell. Caption: "8 inputs → 8 outputs = rule number 110."

**0:10–0:18** — Zoom in on the growing space-time diagram. Repeating background triangular motifs (period-2 background) broken by structures that move — "gliders" in Rule 110. Annotation: "Periodic background." "Glider" pointed to with arrow.

**0:18–0:27** — The gliders collide: two rightward-moving structures meet a leftward-moving structure. The collision produces a new structure. Caption: "Collisions create new structures — like a computer operating on data."

**0:27–0:36** — Text: "Stephen Wolfram, 1985 — Rule 110 is Turing-complete. Proved by Matthew Cook, 2004." Side-by-side comparison: Rule 110 vs. Rule 30 (chaotic, random-looking) vs. Rule 90 (perfect fractal). All three grown from the same single-cell initial condition.

**0:36–0:45** — Wide view: 400 cells wide, 400 generations deep — the full space-time diagram. The pattern is neither purely periodic nor purely random. Bold text: "Universal computation — from 3 cells and a lookup table." Fade to black.

## Physics Concept Teased
Elementary cellular automaton Rule 110: a 1D CA where each cell's next state depends on itself and its two neighbours. With just 8 rules (number 110 in binary), it produces complex behaviour that is Turing-complete — capable of simulating any computation. A minimal universal computer.

## Production Notes
Code complexity: low. Renderer: Canvas 2D. Key algorithm: trivially simple — precompute rule lookup table (array of 8 outputs). For each generation, scan left-to-right and apply rule. Draw each generation as a horizontal stripe on canvas (1px per cell, 1px per generation). For the 400×400 diagram: precompute all 400 generations first, then animate by revealing one row per frame. Gotcha: padded boundary conditions (wrap or zero) affect pattern — use wrapping for periodic patterns. Runtime: real-time.
